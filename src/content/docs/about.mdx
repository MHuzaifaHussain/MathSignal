MathSignal explains the statistics, probability and linear algebra behind machine learning, from the first everyday intuition to the research papers. Every topic has a plot you can move, the exact definitions, worked examples, runnable Python and the sources it relies on.

## Who writes it

MathSignal is written and maintained by Muhammad Huzaifa Hussain. The source is public on [GitHub](https://github.com/MHuzaifaHussain/MathSignal).

## How pages are checked

Before a page is published:

- every formula and number is recomputed;
- every code example is run, and the runnable ones check their own results with assertions;
- every reference is opened and linked to its source;
- the page is read in both light and dark themes, on a phone and with the keyboard alone.

## How AI tools are used

Pages are drafted and reviewed with the help of AI tools. The author checks each page as described above and is responsible for what is published. If something is wrong, it is a mistake to fix, not a feature of the tools.

## Reporting an error

Each page has a "Report an error on this page" link at the bottom, which opens a GitHub issue with the page address filled in. Corrections are made on the page itself.
