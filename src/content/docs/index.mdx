## How each page works

Every concept follows the same path: why it matters in machine learning, an interactive board to build intuition, the explanation, the formal definition, real ML applications, code you can run in the browser, and the mistakes people commonly make.

- **Machine learning** (coming soon): gradient descent, loss functions, backpropagation. Where the maths meets the model.
