Development only. Every table comes from `src/data/distributions.mjs`; the pages pass only the third column. Open each fold, then check at 320 and 375 px that the page never scrolls sideways (at most a table region does), that Tab stops on each region with the ink-and-yellow focus ring, and that a screen reader names each region by its caption and reads the row header before each cell. Print the page with the folds open to check that the regions don't clip. Lab pages have no `topic`, so the footer's "How this page was made" and "Cite this page" show on concept pages only, for example the Normal distribution page.

## Normal: the swap on the Normal page

The first fold holds the markdown table the Normal page used before the swap; the second holds the registry's `PropertiesTable` for the `normal` family. Apart from the caption they must look the same. The second table keeps the default id, `properties`, as on the Normal page: open this page with `#properties` (and switch to it from another hash) to check that its closed fold opens and the region scrolls into view. Every fold here has the id `formal-definition`, which is fine on a draft lab page and never happens on a concept page.
