# 0022: The regression board, rebuilt on an exact model (model now, UI later)

Status: accepted, 2026-11-26, for the model and data sets. The board's UI (setups, reducer, copy, plane, table) follows once the week-3 and week-4 page specs exist; until then the existing `LinearRegression.tsx` is untouched and no page uses it.

## Context
Six week-4 pages (correlation, simple linear regression, Pearson vs Spearman, correlation vs causation, Simpson's paradox, MSE vs MAE vs Huber), the week-3 loss functions page, OLS in week 5 and residual diagnostics in week 8 need one scatter board: residuals, r and R², a rank view, Anscombe's quartet and Simpson data. The current nine-point `LinearRegression` drags free floats, so nothing it prints can be asserted, and it reports R² = 1 when every y is equal, where R² is undefined. Writing the new board's copy before its page specs exist would repeat week 1's rework, so the owner ruled: shared math and the pure model now, the UI after the page specs.

## Decision
1. **The board will be rebuilt in place on setups**, as VectorBoard2D is (0014): one Mafs board picked by a `setup` id, with every handle snapped to whole numbers, the tray (a child choice plus a slider per axis) as the keyboard path and the Mafs handles a pointer shortcut. This record covers its first part: `linearRegression/model.ts` and `linearRegression/datasets.ts`, checked by `npm run check:boards`.
2. **Exact on Fractions, with bounded sums.** Runtime readouts never sum residual by residual: n·Sxx = nΣx² − (Σx)² (and the same for Syy and Sxy) stays small, slope = n·Sxy ÷ n·Sxx, SSE = Syy − Sxy² ÷ Sxx, and r² = (n·Sxy)² ÷ (n·Sxx × n·Syy). With `boardMath`'s LCM-based `addFractions`, `subtractFractions` and `divideFractions` (built earlier this week), a seeded sweep of 3,000 random class drags on the 110 to 165 grid, 1,000 lap-time drags on 30 to 130, every value of child 2's arm span, the all-equal and alternating extremes and Anscombe's four sets throws nowhere, and on every fit the residuals add to 0, Σ residual × (x − x̄) = 0, the closed-form SSE equals the residual-by-residual sum, and r² = R².
3. **Definitions pinned for the regression pages:**
   - r = Sxy ÷ √(Sxx × Syy), the same with ÷ n or ÷ (n − 1). r is exact only when the reduced r² has a perfect-square numerator and denominator (Our class: 16/25, so r = 0.8); otherwise it is a float the copy writes with "≈".
   - residual = actual − predicted.
   - R² = 1 − SSE ÷ Syy for the least-squares line with an intercept. It is undefined when Syy = 0 (no spread to explain) and when Sxx = 0 (no line, so no SSE); it is never written "R² = 1" for either. All x equal makes r, R² and the line undefined; all y equal gives a flat line that misses no one, with r and R² undefined.
   - ρ is r on average ranks (SciPy `rankdata`'s default); the 1 − 6Σd² ÷ (n(n² − 1)) shortcut refuses tied data, and check-boards asserts that it agrees with r on ranks wherever there are no ties.
   - The least-absolute line is the best line through two of the points; `tied` is set only when a different line reaches the same total, so collinear pairs giving one line are not a tie.
4. **Data.** Our class imports DescriptiveStats' nine heights (`CLASS_HEIGHTS`, decision 0015), so child 2 is the same child on every board, and adds the arm spans (means 134 and 132 cm; Sxx = 576, Syy = 900, Sxy = 576). Presets: Perfect line, Shuffled arms (Sxy = 0), One typo (child 2's 124 cm typed as 160: R² = 1/41). Runners: Curve (gains shrink to 1 s a week), Slow start, Straight line, A fall. Shoe reading and Team practice with their groups and the "same feet" and "practice alike" presets. Anscombe's quartet with y in hundredths, from the Rdatasets copy; the 1973 paper itself was not opened, so a page cites it only after someone opens it.
5. **Every number the setups will show is asserted:** Our class (residuals −8, 4, 1, 6, 3, −7, −9, 8, 2; SSE 324; r = 4/5; ρ = 47/60), the reader's lines through 125 cm and 145 cm (900, 360, 333, 333, 5,841/16, 324; 1,908 on One typo), child 4 at 135 cm (r² = 8,649/14,528), child 2's miss under the old line (40 cm, 1,600 squared) and the refit (27 cm), the least-absolute lines (0.9 × height + 14.2 with total 217/5 against the squared line's 48; 5/7 and 284/7 on One typo), the runners (r² = 7,776/9,305, 55,296/122,405, exactly −1, ρ = −0.4 on A fall, and ρ² = 119/120 with the 42 s tie), the grouped fits (pooled slopes 0.6 and −0.8; slopes 0 within each age and 1 within each team) and Anscombe (equal to two decimals; r 0.816, 0.816, 0.816, 0.817; Set IV's lone point has residual 0).

## Alternatives considered
- **A second `LinearRegressionX` component beside the old one.** Two regression boards, one of them dead code with a wrong R².
- **Free float dragging, as today.** No readout could be asserted, and every r would jitter while dragging.
- **Summing squared residuals at runtime.** Exact, but each sum's denominators grow with every term; the bounded closed forms give the same numbers and leave the residual sums to the checks.
- **Spearman's 6Σd² formula as the model.** Wrong with ties, and dragged lap times tie easily.
- **A Huber line.** No closed form; it needs iterative reweighting, so its numbers can't be asserted as fractions.
- **Building the UI in week 2.** Its copy would precede its page specs; the owner ruled model now, UI later.
